# Real-Time Job Analytics Dashboard

## Project Overview
This project analyzes job postings to identify trends in hiring companies, salaries, company size, qualifications, internship preferences, and job locations.

The dashboard was created using Tableau and supported by Python data processing.

## Tools & Technologies
- Tableau
- Python
- Pandas
- Excel
- HTML

## Key Analysis
- Top 10 Hiring Companies
- Qualification and Job Location Analysis
- Salary Range Analysis
- Company Size Analysis
- Internship Preference Distribution
- Job Market Trends

## Tableau Dashboard
View the interactive dashboard here:

https://public.tableau.com/views/realjobportal/Dashboard1

## Project Files
- `job.html` – Project website
- `job_description.py` – Python data processing
- Tableau workbook/dashboard – Job analytics visualization

## Objective
The objective of this project is to analyze real-world job posting data and generate useful insights about hiring patterns, salary ranges, company characteristics, and candidate preferences.
